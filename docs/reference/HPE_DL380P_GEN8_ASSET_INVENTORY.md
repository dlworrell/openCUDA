# HP ProLiant DL380p Gen8 asset inventory

Issue: #36

This is the human-readable index for the machine-readable manifest in `config/hpe-dl380p-gen8-assets.json`.

## Record fields

Each asset should identify:

- component family
- hardware option/model
- operating-system family
- support class
- file/document name
- version/revision
- release date
- vendor document/support ID
- source URL
- retrieval date
- checksum and algorithm when known
- applicable PCI/USB/platform identifiers when known
- redistribution/license status
- live/dead/gated status
- archive/Wayback location if needed
- applicability to the actual openCUDA reference server: `unknown`, `not-installed`, `installed`, or `candidate`
- notes
